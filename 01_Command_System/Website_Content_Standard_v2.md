# FutureWorld Website Content Standard v2

## Purpose

The FutureWorld website is the master knowledge repository of the project.

Website URL:
https://jamilahmad488.github.io/futureworld/

## Core Principle

Social Media = Discovery Layer
Website = Knowledge Layer

## Approved Website Content Types

- HTML Briefings
- HTML Video Stories
- PDF Reports
- PowerPoint Presentations
- Gallery Assets
- Maps
- Charts

## File Size Rules for GitHub Pages

- Images: WEBP preferred, less than 500 KB where possible
- JPG: acceptable for photos
- PNG: use only when transparency or quality is essential
- PDF: preferably 2–10 MB
- PPTX: preferably under 20 MB
- MP4: preferably 5–30 MB
- Large videos: upload to YouTube and embed instead of storing directly

## Required Website Asset Package

For every major topic, create:

1. Main HTML briefing
2. PDF report or report structure
3. PPT presentation or slide structure
4. Gallery asset list
5. Social media landing HTML
6. SEO metadata
7. Internal links
8. CTA directing users to related FutureWorld pages

## Website Design Standard

Use:

- dark futuristic theme
- blue, gold, cyan accents
- cards
- timelines
- maps
- statistics panels
- interactive navigation
- mobile responsiveness
- clear section hierarchy

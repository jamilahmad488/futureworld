# Practical AI & Website Building Course Website Placement Plan

## Published Location

Main course landing page:

`FutureWorld_Website/courses/practical-ai-website-building/index.html`

Public URL:

`https://futureworldintelligence.org/courses/practical-ai-website-building/`

## Website Discovery Location

The course is now linked from:

`FutureWorld_Website/pages/resources.html`

This makes the Resources page the main public entry point for learners.

## Future Module Location

Future public module and lecture pages should be placed in:

`FutureWorld_Website/courses/practical-ai-website-building/modules/`

Recommended pattern:

- `module-01-setting-digital-environment.html`
- `module-02-website-building-from-zero.html`
- `module-03-domain-and-website-launch.html`
- `module-04-search-console-analytics.html`
- `module-05-content-creation-with-ai.html`
- `module-06-social-media-traffic-system.html`
- `module-07-prompt-library.html`
- `module-08-publishing-workflow.html`

## Future Resource Location

Course prompts, checklists, templates and support files should be placed in:

`FutureWorld_Website/courses/practical-ai-website-building/resources/`

## Social Media Traffic Route

Social posts should direct visitors to the course landing page first. Individual module posts can link directly to module pages once those pages exist.

Primary funnel:

Social media post -> Course landing page -> Module page -> Lecture page -> Practice task or resource

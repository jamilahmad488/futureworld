# FutureWorld Website Content Standard v2

## Core Principle

Social Media = Discovery Layer  
Website = Knowledge Layer

## Website Content Requirements

Website content should be:
- Evergreen
- Research-based
- Visually structured
- Mobile-responsive
- Lightweight enough for GitHub Pages
- Suitable for future AI knowledge-base use

## Preferred Website Formats

- HTML briefings
- HTML video stories
- PDF reports
- PPT presentations
- Gallery assets
- Maps and charts

## File Size Guidance

- Images: WEBP preferred, under 500 KB where possible
- PDFs: 2–10 MB preferred
- PPTX: under 20 MB preferred
- MP4: 5–30 MB preferred
- Large videos: upload to YouTube and embed instead of storing on GitHub Pages

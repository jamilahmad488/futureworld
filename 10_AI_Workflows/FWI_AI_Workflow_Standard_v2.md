# FutureWorld AI Workflow Standard v2

## Standard Workflow

Research → Script → Visual Design → Voiceover → Publish → Archive → Analyze

## Tools

- ChatGPT: research, scripts, metadata, captions
- Canva: visuals, videos, slides
- NotebookLM: documentary-style video overviews
- Google Drive: archive and knowledge base
- GitHub Pages: website publication
- Meta Business Suite: Facebook and Instagram scheduling
- TikTok/YouTube: video distribution

## Archive Rule

Every content item should save:
- Topic
- Prompt
- Script
- Visual assets
- Voiceover
- Final video
- Caption
- Source references
- Performance notes

# FutureWorld Intelligence Command System v2

## Purpose

This is the official command system for FutureWorld Intelligence content creation.

## Categories

- ai — Artificial Intelligence
- climate — Climate Systems
- geo — Geopolitics
- energy — Energy Systems
- science — Science and Technology
- future — Future Systems and Foresight

## Commands

### website-c
Website HTML briefing.

### short-c
TikTok + Instagram Reels + Facebook Reels + YouTube Shorts.
Format: 9:16, 1080×1920, MP4.

### yt-c
Long-form YouTube video.
Format: 16:9, 1920×1080.

### substack-c
Newsletter or long-form article.

### report-c
PDF-style research report.

### asset-c
Complete content package. Recommended default.

## Example

ai asset-c
AI Agents Revolution

## Standard Output for asset-c

1. Website HTML Briefing
2. PDF Report Structure
3. PowerPoint Structure
4. Gallery Asset List
5. Social Media Landing HTML
6. Short Video Package
7. Substack Article Structure
8. SEO Metadata
9. Internal Linking Structure
10. Traffic Diversion Strategy

## Confirmation Format

When a FutureWorld command is used, first return:

Category:
Command:
Output Package:

Then proceed with production.

## Help Command

fwi-help

Returns the full command system.

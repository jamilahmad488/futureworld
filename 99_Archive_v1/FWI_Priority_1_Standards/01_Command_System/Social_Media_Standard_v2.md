# FutureWorld Social Media Standard v2

## Purpose

Social media platforms are the traffic generation and discovery layer.

## Platforms Covered by short-c

- TikTok
- Instagram Reels
- Facebook Reels
- YouTube Shorts

## Technical Format

- Aspect ratio: 9:16
- Resolution: 1080×1920 minimum
- Duration: 30–60 seconds preferred
- File format: MP4
- Captions/subtitles: required
- Hook: first 3 seconds
- CTA: final 3–5 seconds

## Standard Structure

0–3 seconds: factual hook
3–15 seconds: context
15–40 seconds: explanation
40–55 seconds: future implication
55–60 seconds: CTA and brand close

Explore the full briefing at FutureWorld Intelligence.
Link in bio.

## Caption Standard

1. One-line factual hook
2. Short context
3. Website direction
4. Hashtags

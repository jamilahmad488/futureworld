# FutureWorld AI Workflow Standard v2

## Core Workflow

Research → Topic Selection → Script / Article Draft → Visual Plan → Website Asset → Social Asset → Publishing → Archive → Analytics Review → Improvement

## Main Tools

### ChatGPT
Research framing, scripts, articles, captions, SEO metadata, HTML briefing planning, and standardization.

### Canva
Videos, presentations, thumbnails, visual cards, and infographics.

### NotebookLM
Video overviews, source-based briefings, documentary-style summaries, and voice-over drafts.

### GitHub Pages
Website hosting and HTML briefing publication.

### Meta Business Suite
Facebook and Instagram management, scheduling, and analytics.

### Google Drive / Laptop Repository
Storage, backups, archives, and AI-ready datasets.

## Archive Rule

Every FutureWorld content item must archive:

- topic
- command used
- prompt
- source references
- script
- article
- visual assets
- final output
- platform caption
- publishing date
- performance notes

## AI-Ready Data Rule

Prefer:

- TXT
- Markdown
- CSV
- JSON
- JSONL

## Human Review Rule

Before publishing, verify:

- factual accuracy
- source quality
- neutrality
- copyright safety
- readability
- visual consistency
- platform suitability

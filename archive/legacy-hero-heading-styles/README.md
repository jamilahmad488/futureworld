# Archived FWI hero-heading styles

The universal hero system at `/assets/fwi-universal-hero.css` supersedes all
earlier hero-heading declarations as of FWI-HERO-1.0.

Most historical hero rules remain embedded inside full page stylesheets. They
also control maps, illustrations, cards, spacing and responsive layouts, so
deleting those complete style blocks would damage the pages. They are retained
only as non-authoritative layout history. The direct
`.fwi-universal-hero-title` class, loaded last, now governs every active H1.

The former standalone publication override has been physically removed from
`/style.css` and archived in this directory.

Archived rules must never be linked from public pages.

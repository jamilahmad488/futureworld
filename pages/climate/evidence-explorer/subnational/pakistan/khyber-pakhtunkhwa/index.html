Provincial Evidence Interface

Live imagery from province to pilot landscape

Live API connection

The map opens at Khyber Pakhtunkhwa scale. Load imagery for the current provincial view, select the Merged Districts, or move directly to the Bajaur pilot extent. Rendering options are retrieved from the Planetary Computer Data API for the selected collection.

The dashed boxes are viewing extents rather than verified administrative polygons. Official boundaries, forest-division limits and intervention sites will be added only after source and geometry validation.

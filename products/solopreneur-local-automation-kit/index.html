Product Overview

Practical local automation for everyday work

The Solopreneur Local Automation Kit is a starter toolkit for freelancers, independent professionals, consultants, solopreneurs and small-business operators. It brings together three focused Python utilities that can be run locally in a compatible environment.

The toolkit is designed to support repetitive information-processing tasks. It is not an autonomous AI agent, a managed online service or a substitute for professional judgement.

Included Tools

Three focused utilities

TOOL 01 · DOCUMENT PROCESSING

PDF Document Extractor

Extracts text and metadata from PDF documents and prepares structured summaries for further review.

  • Extracts available PDF text and metadata.
  • Produces JSON and CSV summaries.
  • Reports page counts and word counts.
  • Checks configured keywords.

Limitation: OCR is not included. Scanned PDFs without an accessible text layer may not yield extractable text.

TOOL 02 · OPPORTUNITY MONITORING

Opportunity Radar

Reads configurable RSS and Atom feeds to help users monitor information relevant to their selected interests and keywords.

  • Reads configured RSS and Atom feeds.
  • Filters entries using configured keywords.
  • Removes duplicate links.
  • Produces Markdown and JSON digests.

Limitation: An internet connection is required. Results depend on the availability, quality and configuration of external feeds and keywords.

TOOL 03 · CONTENT PREPARATION

Content Packager

Processes Markdown drafts and prepares basic structured information to support content review and publication workflows.

  • Creates URL slugs and word counts.
  • Estimates reading time.
  • Generates meta descriptions and keyword suggestions.
  • Suggests social post copy.
  • Generates basic Article JSON-LD structured data.

Limitation: Keyword suggestions are frequency-based, not professional SEO research. Editorial review remains necessary.

Technical Information

Requirements and operation

Runtime

Python 3 and a Bash-compatible terminal.

PDF extraction dependency

The PDF Document Extractor uses pypdf 7.1.0.

Supported environments

Installation guidance is provided for Linux, Ubuntu on Windows Subsystem for Linux (WSL), and macOS.

Connectivity

Opportunity Radar requires an internet connection to retrieve configured RSS and Atom feeds. The other tools are intended for local processing.

API requirements

No paid APIs or API keys are required by the toolkit.
